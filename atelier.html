      Aperçu dans le jeu

      Les icônes font 32 × 32 pixels. Les retouches des trophées vont dans trophees.json, celles des vignettes dans boutique.json ; le bouton Publier envoie tout en une fois.

      Le fond des tuiles (crème, doré, cadenas) est géré par le jeu : seul le dessin se retouche ici.

      Raccourcis : B crayon, E gomme, G remplir, I pipette, S sélection, flèches pour décaler le dessin, Ctrl+Z / Ctrl+Y.

      Copier-coller : Ctrl+C / Ctrl+X copie la sélection (ou toute l'icône), Ctrl+V colle, y compris un dessin copié dans les onglets Accessoires ou Obstacles. Glisse le collage pour le placer, Entrée pour le poser, Échap pour annuler. Ctrl+Maj+V colle une image comme modèle.
